# AFA BANK — design direction

Greenfield build: the supplied brief describes an existing application, but the owner confirmed that this project starts from scratch. No prior backend or customer data exists in this workspace.

Liquid Titanium offers the strongest recognizable product object and material identity; Neo Editorial offers the best typography, clarity, and performance; Cinematic Architecture adds depth but risks distracting from banking tasks and increasing render cost. Choose Liquid Titanium with editorial composition. Midnight navy, cool silver, controlled electric blue, generous whitespace, oversized tightly tracked display type. Avoid floating panel grids.

The AFA Current is an original SVG ribbon. The card is actual rounded Three.js geometry with physical metal material, chip, edges and a procedural brushed texture. Lazy-load 3D; use an accessible CSS fallback and cap DPR. Motion is subordinate to banking actions. Landing tells five chapters; the application uses a restrained ledger composition. All currency values are integer hundredths of ALL. This is an educational simulation only.
